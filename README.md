An independent atelier crafting considered, slow-made garments in natural fibers.

## 📁 Repository Structure
- `index.html` — Homepage with hero showcase and philosophy
- `collections.html` — Seasonal catalog of slow-made garments
- `about.html` — Atelier history, craft, and materials
- `contact.html` — Studio inquiries and visit booking
- `style.css` — Custom styles & color tokens
- `main.js` — Mobile menu & interactive scripts
- `assets/` — Garment and editorial photography
- `robots.txt` & `sitemap.xml` — Search engine optimization (SEO)
